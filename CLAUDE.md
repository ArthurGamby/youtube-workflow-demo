# Guide Claude pour ce repository

## Objectif du projet
Ce projet est une démo réaliste et légère d'un site marketing SaaS (DevPulse) pour illustrer un workflow de développement assisté par IA.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint + Prettier
- Vitest + React Testing Library

## Règles d'exécution
- Garder les changements **petits, ciblés et facilement reviewables**.
- Réutiliser les composants existants dès que possible avant d'en créer de nouveaux.
- Garder une copy orientée conversion (clarté des bénéfices, CTA visibles, crédibilité B2B).
- Mettre à jour les tests lorsque le comportement UI change.
- Exécuter lint et tests avant de proposer une PR.

## Structure recommandée de description de PR
1. **Contexte**
2. **Changements**
3. **Validation**
4. **Linear**
